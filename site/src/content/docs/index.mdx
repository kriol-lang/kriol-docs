## O que é o Kriol?

O **Kriol** (ou **KriolLang**) é uma linguagem de programação que usa palavras do Criolo cabo-verdiano. Onde outras linguagens escrevem, em inglês, `if`, `else` e `print`, o Kriol escreve `si`, `sinau` e `mostraln`.

Foi criada para que quem fala Criolo possa aprender a programar na sua própria língua.

## Um primeiro exemplo

```kriol
// O programa começa sempre na função `inisiu`.
fn inisiu() {
    // Guarda o número 16 na variável `idadi`.
    int idadi = 16;

    // `si` decide: se a condição for verdadeira, corre o primeiro bloco;
    // senão (`sinau`), corre o segundo.
    si idadi >= 18 {
        mostraln("Já és maior de idade.");
    } sinau {
        mostraln(f"Ainda tens {idadi} anos: faltam {18 - idadi} para a maioridade.");
    }
}
```

**Saída:**

```
Ainda tens 16 anos: faltam 2 para a maioridade.
```

:::tip[Experimenta sem instalar nada]
Copia este programa para o [playground](https://play.kriol.dev), que corre Kriol no navegador, e clica em **Executar**. Depois muda o `16` para `20` e executa outra vez.
:::

## Para quem já programa

O Kriol é uma linguagem imperativa, de tipagem estática e compilada, com uma sintaxe próxima da do C, do Go e do Rust. Os tipos são verificados na compilação, e o compilador `kriol` gera, através do LLVM, um executável nativo ou um módulo WebAssembly.

O [Vocabulário](./referencia/vocabulario/) traduz as palavras-chave numa página, e a [Especificação Formal](./referencia/especificacao/) tem a gramática. Depois vê [Erros](./linguagem/erros/) e [Conversão de Tipos](./linguagem/conversao-de-tipos/), as duas partes onde o Kriol não se comporta como o C.
