## Pré-requisitos

O Kriol funciona em **Linux** e **Windows** (x86_64). O suporte para Windows é experimental. Suporte para macOS está planeado para o futuro.

Precisas ter:
- No Linux, um compilador C (GCC ou Clang), usado para ligar os programas
- No Windows, nada mais: o compilador já traz tudo o que precisa
- Uma conexão à internet para a instalação

:::note[Experimentar no playground]
Também podes testar a linguagem no [playground Kriol](https://play.kriol.dev) antes de instalar o compilador. O playground executa no contexto do navegador, por isso algumas capacidades do ambiente nativo, como acesso direto ao sistema de ficheiros ou a processos externos, podem estar limitadas.
:::

## Instalação

### Linux

A forma mais fácil de instalar o Kriol é através do script de instalação:

```bash
curl -fsSL https://kriol.dev/install.sh | sh -s -- --pre
```

Depois, adiciona o Kriol ao teu PATH. Adiciona esta linha ao ficheiro de configuração do teu shell (como `~/.bashrc` ou `~/.zshrc`):

```bash
export PATH="$HOME/.kriol:$PATH"
```

Fecha e reabre o terminal, e verifica se funcionou:

```bash
kriol --version
```

### Windows (experimental)

:::caution[Suporte experimental]
Os executáveis para Windows ainda não têm assinatura digital, por isso o Windows pode impedir que sejam executados. Se isso acontecer, vê [Se o Windows bloquear o kriol.exe](#se-o-windows-bloquear-o-kriolexe).
:::

No PowerShell, executa:

```powershell
& ([scriptblock]::Create((irm https://kriol.dev/install.ps1))) -Pre
```

O Kriol fica instalado em `%LOCALAPPDATA%\Programs\kriol` e é adicionado ao teu `PATH`. Abre um novo terminal e verifica se funcionou:

```powershell
kriol --version
```

Também podes descarregar o ficheiro `kriol-<versão>-windows-x86_64.zip` da [página de versões](https://github.com/kriol-lang/kriol/releases) e usá-lo diretamente; mantém o `kriol.exe` e o `ld.lld.exe` na mesma pasta. Os programas compilados funcionam no Windows 7 e versões posteriores.

#### Se o Windows bloquear o kriol.exe

Como o `kriol.exe` e o `ld.lld.exe` não têm assinatura digital, ao executá-los podes ver um erro como *"Uma política de Controlo de Aplicações bloqueou este ficheiro"* (em inglês, *"An Application Control policy has blocked this file"*) ou um aviso do SmartScreen a dizer *"O Windows protegeu o seu PC"*. Isto vem das funcionalidades de segurança do Windows, não do Kriol. Para contornar:

1. Se descarregaste o `.zip` manualmente, desbloqueia os ficheiros e tenta de novo. Executa isto na pasta onde o extraíste, ou no `.zip` antes de o extrair:

   ```powershell
   Get-ChildItem -Recurse | Unblock-File
   ```

   No aviso do SmartScreen, também podes escolher **Mais informações → Executar mesmo assim**. O script de instalação já desbloqueia os ficheiros e avisa-te se o Windows continuar a bloquear o `kriol.exe`.

2. Se o erro da *política de Controlo de Aplicações* continuar, é o **Controlo Inteligente de Aplicações** (*Smart App Control*) que está a bloquear programas sem assinatura. Podes ver o estado dele em *Segurança do Windows → Controlo de aplicações e browser → Controlo Inteligente de Aplicações*. Nesse caso, recomendamos usar a versão para Linux dentro do [WSL](https://learn.microsoft.com/pt-pt/windows/wsl/install), que te permite manter o Controlo Inteligente de Aplicações ativo. Instala o WSL a partir do PowerShell e reinicia o computador quando te for pedido:

   ```powershell
   wsl --install
   ```

   Depois, no terminal do WSL (Ubuntu), instala um compilador C e o Kriol, como nas [instruções para Linux](#linux):

   ```bash
   sudo apt update && sudo apt install -y gcc curl
   curl -fsSL https://kriol.dev/install.sh | sh -s -- --pre
   ```

3. Caso contrário, por agora a única forma de contornar o Controlo Inteligente de Aplicações é desativá-lo no mesmo sítio. Em muitas versões do Windows 11 não é possível voltar a ativá-lo sem reinstalar o Windows, por isso pensa bem antes. Também podes [compilar o Kriol de origem](#compilar-de-origem-opcional).

4. Em computadores geridos por uma empresa ou escola, o bloqueio pode vir de uma política de TI. Pede ao administrador que autorize os ficheiros.

## O teu primeiro programa

Cria um ficheiro chamado `ola-mundu.kriol`:

```kriol title="ola-mundu.kriol"
fn inisiu() {
    mostran("Kualeh, Mundu!");
}
```

:::note
A função `inisiu` é o ponto de entrada de qualquer programa Kriol, equivalente ao `main` em C.
:::

### Compilar e executar

Compila o programa:

```bash
kriol ola-mundu.kriol -o ola-mundu
```

Executa:

```bash
./ola-mundu
```

No Windows, o compilador acrescenta `.exe` ao nome, e o programa executa-se com `.\ola-mundu.exe`.

Os programas são otimizados por omissão (nível 2). Podes escolher outro nível com `--opt-lvl <n>`, de `0` (sem otimização) a `3`.

**Saída:**

```
Kualeh, Mundu!
```

### Mensagens de erro

Quando o programa tem um erro, o compilador indica o ficheiro, a linha e o que está mal, e muitas vezes sugere como corrigir:

```
ola-mundu.kriol:2: erro: a variável 'nomi' não foi declarada; declara-a antes de a usar, por exemplo 'int nomi = 0;'
```

Os erros que só acontecem com o programa a correr, como um índice fora dos limites de um array, seguem o mesmo formato:

```
ola-mundu.kriol:5: erro de execução: o índice 3 está fora do array, que vai de 0 a 2
```

Os editores de código reconhecem o formato `ficheiro:linha:` e permitem saltar para a linha indicada.

## Estrutura básica de um programa

Todo programa Kriol precisa de uma função `inisiu` sem parâmetros:

```kriol
fn inisiu() {
    // código aqui
}
```

Podes declarar outras funções antes ou depois de `inisiu`. A ordem não importa para chamadas entre funções do mesmo ficheiro.

## Extensões de ficheiro

Os ficheiros Kriol usam `.kriol` (preferida) ou `.kr` (abreviada).

## Exemplo: Fibonacci recursivo

```kriol title="fibonacci.kriol"
fn fibo(int n) int {
    konfirma(n >= 0);

    si n <= 1 {
        divolvi 1;
    } sinon {
        divolvi fibo(n - 1) + fibo(n - 2);
    }
}

fn inisiu() {
    int[10] seq = [0; 10];

    pa int i = 0; i < 10; i += 1 {
        seq[i] = fibo(i);
    }

    mostran(f"A sequência de Fibonacci até o 10º elemento é {seq}");
}
```

## Compilar de origem (opcional)

Se quiseres compilar o compilador de origem, precisas de:

- Clang, LLVM e LLD 20
- bison e flex
- cmake

No Debian/Ubuntu:

```bash
apt install make flex bison clang-20 llvm-20 llvm-20-dev llvm-20-tools lld-20 zlib1g-dev libzstd-dev cmake wasi-libc libclang-rt-20-dev-wasm32
```

Obtém o código, incluindo o submódulo do coletor de lixo, e compila:

```bash
git clone --recursive https://github.com/kriol-lang/kriol
cd kriol
cmake -B build && cmake --build build
```

Executa:

```bash
./build/kriol --help
```

Para compilar no Windows, segue as instruções do `README.md` do [repositório](https://github.com/kriol-lang/kriol). Para mais exemplos, vê a pasta `examples/`.
