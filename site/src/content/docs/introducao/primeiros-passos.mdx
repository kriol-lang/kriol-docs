## Pré-requisitos

O Kriol funciona em **Linux** e **Windows** (x86_64). Suporte para macOS está planeado para o futuro.

Precisas ter:
- No Linux, um compilador C (GCC ou Clang), usado para ligar os programas
- No Windows, nada mais: o compilador já traz tudo o que precisa
- Uma conexão à internet para a instalação

:::note[Experimentar no playground]
Também podes testar a linguagem no [playground Kriol](https://play.kriol.dev) antes de instalar o compilador. O playground executa no contexto do navegador, por isso algumas capacidades do ambiente nativo, como acesso direto ao sistema de ficheiros ou a processos externos, podem estar limitadas.
:::

## Instalação

### Linux

A forma mais fácil de instalar o Kriol é através do script de instalação:

```bash
curl -fsSL https://raw.githubusercontent.com/kriol-lang/kriol/refs/heads/main/install.sh | sh -s -- --pre
```

Depois, adiciona o Kriol ao teu PATH. Adiciona esta linha ao ficheiro de configuração do teu shell (como `~/.bashrc` ou `~/.zshrc`):

```bash
export PATH="$HOME/.kriol:$PATH"
```

Fecha e reabre o terminal, e verifica se funcionou:

```bash
kriol --version
```

### Windows

No PowerShell, executa:

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/kriol-lang/kriol/refs/heads/main/install.ps1))) -Pre
```

O Kriol fica instalado em `%LOCALAPPDATA%\Programs\kriol` e é adicionado ao teu `PATH`. Abre um novo terminal e verifica se funcionou:

```powershell
kriol --version
```

Também podes descarregar o ficheiro `kriol-<versão>-windows-x86_64.zip` da [página de versões](https://github.com/kriol-lang/kriol/releases) e usá-lo diretamente; mantém o `kriol.exe` e o `ld.lld.exe` na mesma pasta. Os programas compilados funcionam no Windows 7 e versões posteriores.

## O teu primeiro programa

Cria um ficheiro chamado `ola-mundu.kriol`:

```kriol title="ola-mundu.kriol"
fn inisiu() {
    mostran("Kuale, Mundu!");
}
```

:::note
A função `inisiu` é o ponto de entrada de qualquer programa Kriol, equivalente ao `main` em C.
:::

### Compilar e executar

Compila o programa:

```bash
kriol ola-mundu.kriol -o ola-mundu
```

Executa:

```bash
./ola-mundu
```

No Windows, o compilador acrescenta `.exe` ao nome, e o programa executa-se com `.\ola-mundu.exe`.

Os programas são otimizados por omissão (nível `-O2`). Podes escolher outro nível com `-O0` (sem otimização) a `-O3`.

**Saída:**

```
Kuale, Mundu!
```

## Estrutura básica de um programa

Todo programa Kriol precisa de uma função `inisiu` sem parâmetros:

```kriol
fn inisiu() {
    // código aqui
}
```

Podes declarar outras funções antes ou depois de `inisiu`. A ordem não importa para chamadas entre funções do mesmo ficheiro.

## Extensões de ficheiro

Os ficheiros Kriol usam `.kriol` (preferida) ou `.kr` (abreviada).

## Exemplo: Fibonacci recursivo

```kriol title="fibonacci.kriol"
fn fibo(nter n) nter {
    konfirma(n >= 0);

    si n <= 1 {
        divolvi 1;
    } sinon {
        divolvi fibo(n - 1) + fibo(n - 2);
    }
}

fn inisiu() {
    nter[10] seq = [0] * 10;

    pa nter i = 0; i < 10; i += 1 {
        seq[i] = fibo(i);
    }

    mostran(f"A sequência de Fibonacci até o 10º elemento é {seq}");
}
```

## Compilar de origem (opcional)

Se quiseres compilar o compilador de origem, precisas de:

- Clang, LLVM e LLD 20
- bison e flex
- cmake

No Debian/Ubuntu:

```bash
apt install make flex bison clang-20 llvm-20 llvm-20-dev llvm-20-tools lld-20 zlib1g-dev libzstd-dev cmake wasi-libc libclang-rt-20-dev-wasm32
```

Obtém o código, incluindo o submódulo do coletor de lixo, e compila:

```bash
git clone --recursive https://github.com/kriol-lang/kriol
cd kriol
cmake -B build && cmake --build build
```

Executa:

```bash
./build/kriol --help
```

Para compilar no Windows, segue as instruções do `README.md` do [repositório](https://github.com/kriol-lang/kriol). Para mais exemplos, vê a pasta `examples/`.
