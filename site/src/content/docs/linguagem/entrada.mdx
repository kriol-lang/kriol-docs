## Conceito

A função `toma` lê uma linha de `stdin` e retorna um valor `textu`. Ela aceita uma mensagem de prompt opcional.

`toma` é uma função embutida do prelúdio: está sempre disponível, mas o nome é reservado e não pode ser redefinido.

## Sintaxe

```kriol
toma()
toma("Mensagem para o utilizador: ")
```

O valor retornado não inclui a quebra de linha final. Em ficheiros com quebras de linha Windows, o `\r` final também é removido.

## Exemplos

### Leitura de string

```kriol
textu nome = toma("Digite o seu nome: ");
mostran(f"Olá, {nome}!");
```

### Leitura sem prompt

```kriol
textu linha = toma();
mostran(f"Recebido: {linha}");
```

### Composição com conversão

`toma` retorna sempre `textu`. Conversão para `nter`, `num` ou outros tipos deve ser feita por uma funcionalidade de parsing/conversão explícita futura.

## Considerações em aberto

- Tratamento de erros de conversão (ex: utilizador escreve texto quando se espera `nter`)
- Leitura de múltiplos valores
- Parsing de `textu` para tipos numéricos
