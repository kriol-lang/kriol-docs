## Conceito

A função `toma` lê uma linha de `stdin` e retorna um valor `textu`. Ela aceita uma mensagem de prompt opcional.

`toma` é uma função embutida do prelúdio: está sempre disponível, mas o nome é reservado e não pode ser redefinido.

## Quando a leitura falha

Ler pode falhar: a entrada pode ter terminado (por exemplo, quando o utilizador fecha a entrada com `Ctrl+D`, ou quando o ficheiro redirecionado acaba) ou pode não ser possível lê-la. `toma` falha então com um `Erru` cuja mensagem é `end of input` (a entrada acabou sem dados) ou `failed to read from stdin` (a leitura falhou). Uma última linha sem quebra de linha é lida normalmente.

Podes tratar a falha (vê [Erros](/linguagem/erros/)), ou não fazer nada:

- `toma()` sozinho termina o programa com `kriol: panic at line N: end of input` se a entrada acabar. É o mais simples, e adequado para programas curtos.
- `tenta toma()` passa o erro a quem chamou, por isso só se usa numa função que declare `: Erru`.
- `toma() sinon "valor"` usa um texto por omissão quando a leitura falha.

## Sintaxe

```kriol
toma()
toma("Mensagem para o utilizador: ")
tenta toma()        // passa o erro adiante (função com `: Erru`)
toma() sinon ""     // valor por omissão
```

O valor retornado não inclui a quebra de linha final. Em ficheiros com quebras de linha Windows, o `\r` final também é removido.

## Exemplos

### Leitura de string

```kriol
fn inisiu() {
    textu nome = toma("Digite o seu nome: ");
    mostran(f"Olá, {nome}!");
}
```

### Valor por omissão se a entrada acabar

```kriol
fn inisiu() {
    textu nome = toma("Digite o seu nome: ") sinon "visitanti";
    mostran(f"Olá, {nome}!");
}
```

### Composição com conversão

`toma` devolve sempre `textu`. Para ler um número, converte o texto com `tipo::konverti` (vê [Conversão de tipos](/linguagem/conversao-de-tipos/)):

```kriol
fn inisiu() : Erru {
    textu entrada_idadi = tenta toma("Idadi: ");
    int idadi = tenta int::konverti(entrada_idadi);
    mostran(f"Para o ano terás {idadi + 1}.");
}
```

Se o utilizador escrever algo que não é um número, `int::konverti` falha com um erro como `invalid integer 'abc'`. Para voltar a pedir o valor, usa `sinon` num ciclo:

```kriol
fn inisiu() {
    int idadi = -1;
    nkuantu idadi < 0 {
        textu entrada_idadi = toma("Idadi: ");
        idadi = int::konverti(entrada_idadi) sinon -1;
    }
    mostran(f"Idadi: {idadi}");
}
```
