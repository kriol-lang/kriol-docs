## Conceito

A função `toma` lê uma linha de `stdin` e retorna um valor `textu`. Ela aceita uma mensagem de prompt opcional.

`toma` é uma função embutida do prelúdio: está sempre disponível, mas o nome é reservado e não pode ser redefinido.

## Quando a leitura falha

Ler pode falhar: a entrada pode ter terminado (por exemplo, quando o utilizador fecha a entrada com `Ctrl+D`, ou quando o ficheiro redirecionado acaba) ou pode não ser possível lê-la. Por isso `toma` é uma função que pode falhar, com o erro `Erru`, e o resultado **tem de ser tratado** com `tenta` ou `sinon` (vê [Erros](/linguagem/erros/)):

- `tenta toma()` passa o erro a quem chamou, por isso só se usa numa função que declare `: Erru`, como `inisiu`.
- `toma() sinon "valor"` usa um texto por omissão quando a leitura falha.

A mensagem do erro é `end of input` quando a entrada acabou sem dados, ou `failed to read from stdin` quando a leitura falhou. Uma última linha sem quebra de linha é lida normalmente.

## Sintaxe

```kriol
tenta toma()
tenta toma("Mensagem para o utilizador: ")
toma() sinon ""
```

O valor retornado não inclui a quebra de linha final. Em ficheiros com quebras de linha Windows, o `\r` final também é removido.

## Exemplos

### Leitura de string

```kriol
fn inisiu() : Erru {
    textu nome = tenta toma("Digite o seu nome: ");
    mostran(f"Olá, {nome}!");
}
```

### Valor por omissão

```kriol
fn inisiu() {
    textu nome = toma("Digite o seu nome: ") sinon "visitanti";
    mostran(f"Olá, {nome}!");
}
```

### Composição com conversão

`toma` devolve sempre `textu`. Conversão para `int`, `num` ou outros tipos deve ser feita por uma funcionalidade de parsing/conversão explícita futura.
