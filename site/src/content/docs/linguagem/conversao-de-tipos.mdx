## Conversão implícita (widening)

O Kriol converte automaticamente valores numéricos quando a conversão é um
alargamento seguro:

| De                         | Para                         | Automático |
|----------------------------|------------------------------|------------|
| `bool`                     | inteiro ou ponto flutuante   | ✅ Sim     |
| inteiro menor compatível   | inteiro maior compatível     | ✅ Sim     |
| inteiro                    | ponto flutuante              | ✅ Sim     |
| `f32`                      | `f64` / `num`                | ✅ Sim     |
| `int` / `i64`             | `num` / `f64`                | ✅ Sim     |

```kriol
int x = 5;
num y = x;       // ok, alargamento automático int para num

fn aceita_num(num n) {
    mostran(n);
}

fn inisiu() {
    aceita_num(10);   // ok, int 10 é alargado para num
}
```

:::note
O resultado de uma divisão com `/` é sempre real (`num`), mesmo entre dois inteiros. Por isso `int c = 7 / 2;` é um erro de compilação, e `num c = 7 / 2;` guarda `3.5`. Vê [Operadores](/linguagem/operadores/#a-divisão-é-sempre-real).
:::

:::note
O retorno de uma função também suporta alargamento: se a função retorna `num` e fazes `divolvi` de um `int`, o valor é automaticamente convertido.
:::

## Conversão explícita (cast)

Uma conversão que pode perder informação tem de ser pedida explicitamente, escrevendo o tipo de destino entre parênteses antes do valor, como em C:

```kriol
int a = (int) 3.9;         // 3
num b = (num) a / 2;       // 1.5
u8 c = (u8) 300;           // 44
bool d = (bool) 5;         // sin
```

O *cast* é um operador unário: liga mais forte do que os operadores binários, por isso `(int) 3.9 + 1` é `((int) 3.9) + 1`. Usa parênteses para converter uma expressão inteira: `(int) (x + 1.5)`.

### O que cada conversão faz

| De                   | Para                 | Comportamento |
|----------------------|----------------------|---------------|
| real                 | inteiro              | Trunca em direção a zero (`-3.9` dá `-3`). Valores fora do intervalo ficam no limite do tipo (por exemplo `(u8) 1000.5` dá `255`) e `NaN` dá `0` |
| inteiro              | inteiro mais estreito | Mantém os bits menos significativos (`(u8) 300` dá `44`, `(i8) 200` dá `-56`) |
| inteiro              | real                 | O valor mais próximo representável |
| real                 | outro real           | Arredonda ao tipo de destino (`f64` para `f32`) |
| `bool`               | número               | `sin` dá `1` e `nau` dá `0` |
| número               | `bool`               | `nau` se for zero, `sin` caso contrário |

### O que não se pode converter

Só números e `bool` são alvos válidos, e só números e `bool` se convertem. Estas conversões são erros de compilação:

```kriol
int n = (int) "5";      // ERRO: não se converte texto
textu t = (textu) 5;    // ERRO: o destino não pode ser textu
int m = (int) lista;    // ERRO: não se converte um array ou um molde
```

A conversão entre texto e números pode falhar (o texto pode não ser um número), por isso será uma funcionalidade à parte, que usa o mecanismo de [erros](/linguagem/erros/).
