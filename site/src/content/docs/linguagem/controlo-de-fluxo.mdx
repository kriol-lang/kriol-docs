## Condicional `si` / `sinon`

```kriol
si <condição> {
    // bloco verdadeiro
} sinon {
    // bloco falso (opcional)
}
```

```kriol
int x = 10;

si x > 5 {
    mostran("x é maior que 5");
} sinon {
    mostran("x é 5 ou menos");
}
```

### `sinon si` (else if)

```kriol
si x > 100 {
    mostran("grande");
} sinon si x > 10 {
    mostran("médio");
} sinon {
    mostran("pequeno");
}
```

:::note
As chavetas `{ }` são **sempre obrigatórias**, mesmo para blocos de uma só instrução.
:::

## Ciclo `nkuantu` (while)

Executa enquanto a condição for verdadeira:

```kriol
nkuantu <condição> {
    // corpo
}
```

```kriol
int i = 0;
nkuantu i < 5 {
    mostran(i);
    i += 1;
}
```

## Ciclo `pa` (for)

```kriol
pa <inicialização>; <condição>; <incremento> {
    // corpo
}
```

```kriol
pa int i = 0; i < 10; i += 1 {
    mostra(i);
}
```

O incremento pode ficar de fora. Nesse caso o `pa` tem só a inicialização e a condição, e é o corpo que atualiza a variável:

```kriol
pa int i = 0; i < 10 {
    mostra(i);
    i += 2;
}
// imprime 02468
```

A variável declarada na inicialização só existe dentro do ciclo.

## `kebra` (break)

Termina o ciclo imediatamente:

```kriol
int i = 0;
nkuantu i < 100 {
    si i == 5 {
        kebra;
    }
    mostran(i);
    i += 1;
}
// imprime 0, 1, 2, 3, 4
```

## `kontinua` (continue)

Avança para a próxima iteração do ciclo:

```kriol
pa int i = 0; i < 10; i += 1 {
    si i == 5 {
        kontinua;
    }
    mostran(i);
}
// imprime 0, 1, 2, 3, 4, 6, 7, 8, 9
```

:::caution
`kebra` e `kontinua` fora de um ciclo são erros de compilação.
:::

## `sai` (exit)

Termina o programa com um código de saída:

```kriol
sai(0);    // saída com sucesso
sai(1);    // saída com erro
```

## `konfirma` (assert)

Verifica uma condição em tempo de execução. Se a condição for falsa, o programa termina com erro:

```kriol
konfirma(x >= 0);         // falha se x < 0
konfirma(1 == 1);         // sempre passa
konfirma(!nau);           // sempre passa
```

Podes acrescentar uma mensagem (um `textu`, incluindo uma f-string) que é mostrada quando a condição falha:

```kriol
konfirma(x >= 0, "x não pode ser negativo");
konfirma(i < tamanho, f"índice {i} fora do limite {tamanho}");
```

Sem mensagem, o programa indica `a condição de konfirma é falsa` e a linha. Útil para pré-condições e validações durante o desenvolvimento.

## `paniku` (panic)

Termina o programa de imediato com uma mensagem de erro e a linha onde foi chamado. Serve para situações que nunca deviam acontecer, isto é, bugs do programa:

```kriol
fn dia_da_semana(int n) textu {
    si n == 1 { divolvi "segunda"; }
    si n == 2 { divolvi "terça"; }
    paniku(f"dia inválido: {n}");
}
```

A saída de `paniku("...")` é `programa.kriol:N: erro de execução: ...`, e o programa termina com o código 1. Como `paniku` nunca regressa, uma função com tipo de retorno não precisa de `divolvi` depois dele (o mesmo vale para `sai`).
